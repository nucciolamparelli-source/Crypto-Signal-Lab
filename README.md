# Crypto Signal Lab

Dashboard gratuita per simulare strategie di trading crypto e generare segnali BUY/SELL/HOLD con ChatGPT e Gemini.

## Come usare
1. Crea account Streamlit Community Cloud: https://share.streamlit.io
2. Carica questo repo.
3. Imposta API key come Secrets:
OPENAI_API_KEY="..."
GEMINI_API_KEY="..."
4. Clicca "Esegui Backtest" nella dashboard.
